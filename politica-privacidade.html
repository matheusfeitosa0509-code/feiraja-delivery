Esta página descreve, em linguagem simples, como o FeiraJá trata os dados necessários para cadastro, pedidos e entregas. Antes de publicar como versão final, o responsável pela loja deve revisar e completar os campos indicados.

Dados tratados

Podem ser tratados nome, e-mail, telefone, endereço, CPF quando necessário para o fluxo de pagamento, itens e valor do pedido, forma de pagamento e status. Dados de autenticação são gerenciados pelo Supabase; dados de pagamento Pix são processados pelo Mercado Pago. Não informe senhas de banco nem dados de cartão no campo de observações.

Finalidades e bases

Os dados são utilizados para criar e proteger a conta, registrar e acompanhar pedidos, processar pagamentos, organizar entregas/retiradas, prestar atendimento e cumprir obrigações legais. O responsável deve confirmar as bases legais aplicáveis e os prazos de retenção de acordo com a operação real.

Compartilhamento e segurança

Dados necessários podem ser compartilhados com os provedores de hospedagem, autenticação, banco de dados e pagamento usados para operar o FeiraJá. São aplicados controles de acesso e políticas de segurança, mas nenhum sistema pode prometer risco zero.
